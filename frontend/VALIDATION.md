## 모바일·입력 오류 보완 — 2026-10-13

### 수행 날짜

10월 9~11일 총 3회의 완료 기록은 확인되지 않았습니다. 중간 원격 조회는 자동 승인 검토 시간 초과로 중단되었고, 이후 재시도는 성공했습니다. 아래는 중단된 점검을 이어서 실제로 검증한 결과이며, 예정 날짜의 3회 점검을 완료한 것으로 소급 기록하지 않습니다.

### 재현한 문제와 최소 수정

- 상세 모달 마지막 탭에서 Tab을 누르면 포커스가 배경으로 이탈함: 포커스 순환, 배경 스크롤 제한, Escape 닫기, 원래 항목으로 포커스 복귀 추가.
- 0바이트 PNG도 확인 화면으로 넘어감: 빈 파일을 명확한 안내와 함께 차단.
- 입력이 바뀌어도 완료/확인 상태를 재사용할 가능성이 있음: 파일·자료 유형·기준일·가족 변경 시 확인 입력과 안내를 초기화하고 가족 변경 시 네이티브 파일 입력도 새로 생성.
- 숫자 입력의 float 변환과 비정상 지수 입력 가능성: 문자열 Decimal 검증으로 0과 정밀도를 보존하고 음수/지수/NaN 및 누락 단위를 차단.
- 긴 텍스트, 좁은 화면 입력행, 상세 정의 목록을 위한 줄바꿈/축소 및 모바일 입력행 보완. 색상·대시보드 구성·업무 흐름은 유지.

### 통과한 확인

- 계약 fixture 검사, 새 입력 검증 테스트, TypeScript strict 검사, Vite 배포 빌드 (32 모듈).
- 360/390/768/1280px에서 대시보드와 등록 확인 입력행의 document scrollWidth가 clientWidth와 같아 가로 넘침 없음. 모바일 메뉴는 기존의 가로 스크롤 방식을 유지하며 버튼 높이는 44px로 보완.
- 390px 상세 모달 Tab/Shift+Tab 순환, Escape 닫기 및 원래 제품 버튼으로 포커스 복귀.
- 브라우저에서 파일 누락 안내, 0바이트 파일 차단, 유효 가상 PNG의 확인 화면 이동.
- 브라우저에서 `1e309` 차단 메시지와 확정 버튼 비활성화, `0 mg` 확정 허용.
- 실제 키보드 날짜 변경 시 이전 완료 안내 제거. 날짜 도구의 프로그램식 fill만으로는 React 변경이 발생하지 않아 사용자 키보드 입력으로 검증함.
- 검색 결과 없음 안내, 미동의 가족 접근 안내, 다른 가족 선택 후 이전 검색어 초기화 및 목록 복원.
- 자동 테스트에서 10MB 경계/초과, 잘못된 확장자, Excel/이미지 형식 구분, 공백 제품명, 누락 함량/단위, 음수, NaN, 정밀 소수 검사.

### 남은 범위

실제 API가 연결되지 않아 loading/서버 오류/재시도/401·403/느린 응답/서버 저장 및 실제 가족 권한은 미검증입니다. 실제 데이터 대신 가상 PNG와 가상 이름만 사용했습니다. 실제 모바일 기기·스크린리더 전체 점검과 다중 성분 입력 UI는 남아 있습니다. 백엔드·공통 Schema/API 문서는 변경하지 않았습니다.

### 환경 문제와 해소

초기 sandbox 빌드는 realpath 권한 오류, sandbox Edge는 임시 프로필 권한 오류, 별도 실행 환경 간 서버 연결은 timeout이 발생했습니다. 동일한 허용 실행 환경의 로컬 서버와 headless Edge로 전환한 후 최종 테스트·빌드는 종료 코드 0으로 통과했습니다. 오류를 코드 성공으로 간주하지 않았습니다.

### 범위 제한

실제 AI와 사용자 수정 저장·확정 API는 미연동입니다. 실환자 자료나 API 키를 사용하지 않았고, `user_confirmed=true`는 원본 record를 변경하지 않는 로컬 초안 상태입니다. 공통 스키마/API와 팀장 통합본은 수정·병합하지 않았습니다. 실제 모바일 기기, 전체 스크린리더, 실제 이미지 업로드 E2E는 미검증입니다. 로컬 원본 미리보기 기능은 구현했으나 이번 자동 브라우저 테스트는 파일 없이 가상 결과로 수행했습니다.
