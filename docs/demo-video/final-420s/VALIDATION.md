# 약이음 7분 영상 마감 보완 기록

## 판정

세 가지 영상의 제작·수치 검사·프레임 검토를 진행했습니다. **음질·발음·청취에 의한 내레이션 싱크·이어폰/일반 PC 스피커 명료도·음악 구절의 자연스러움은 직접 청취하지 못했으며 미검증입니다.** 자동 검사와 직접 청취를 구분합니다.

## 기존 실행 기록의 표시

- 현재 작업공간의 저장소 문서·출력 이미지·검증 기록을 확인했으나, 요청된 두 성공 흐름을 보여 주는 것으로 출처가 확인된 실제 Render 실행 캡처를 확보하지 못했습니다.
- 검색에서 확인된 자료는 로컬 Mock 촬영, 합성 이미지, 편집용 설명 카드, 사용자 확인 기록 및 관리자 실조회 JSON입니다. 설명 카드나 일부 조회 JSON을 실제 성공 화면으로 사용하지 않았습니다.
- 모든 해당 카드에 **‘사용자가 제공한 기존 실행 기록 요약’**과 **‘실제 실행 화면 캡처가 아닌 설명 카드입니다.’**를 명시했습니다. 상단 배지도 ‘기존 기록 요약’으로 변경했습니다.
- 사진: 실제 Gemini 추출 + 가상 의약품 매칭·비교·저장·재조회 사용자 확인 기록의 요약.
- HIRA: 단일 합성 제품의 실제 식약처 매칭·비교·저장·재조회 사용자 확인 기록의 요약.
- 신규 Mock 화면을 실제 실행 증거 화면으로 바꾸지 않았습니다. 실제 API 추가 호출 0회.

- 도입 10초, 저장 목록 6초, 마무리 단계 화면 9초는 처음 2초 동안 위치를 보여 준 뒤 같은 실제 프레임의 핵심 영역을 크게 표시하도록 보완했습니다. 앱 코드나 화면 데이터를 변경하지 않았습니다.
- 가족 선택 크롭은 약이음 제목·선택 가족·메뉴를 포함하는 기존 수정값을 유지합니다.

## 마지막 음성·음악의 수치 확인

- 마지막 음성 파일은 끝까지 사용하며 배치상 종료가 약 418.33초입니다. −55dBFS보다 큰 마지막 음성 샘플은 약 418.16초로, 약 1.8초의 여유가 있습니다.
- 음악은 415–420초 페이드아웃을 유지합니다. 음악/믹스 마지막 100ms의 피크는 약 −64.2dBFS입니다. 수치상 급격한 종료를 피하도록 처리했습니다.
- 음악 페이드인 3초, 원곡 반복 4초 선형 크로스페이드 유지. 주관적 구절 연결과 말끝 청취는 미검증입니다.

## 음량 설정 — 유지

- TTS 각 파일: 원본 대비 −2dB, 속도 1.0배.
- 피아노 기본: 원본 대비 −14dB.
- 내레이션 구간 추가 하향: −6dB, 진입 250ms / 복귀 1000ms.
- 음성 신호 덕킹: threshold 0.05 / ratio 6 / attack 30ms / release 1000ms / knee 4 / makeup 1.
- 믹스 자동 증폭 없음. 리미터 limit 0.95 / 자동 증폭 끔 / 지연 보정 켬.
- 개별 입력 레벨·실제 출력 레벨·클리핑·모노 수치 검사는 첨부 JSON 참조. 수치를 실제 청취나 명료도 보증으로 해석하지 않습니다.
