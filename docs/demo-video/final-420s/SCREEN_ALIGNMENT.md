## 세부 연결 확인
- 가족 설명: 2번 시작 부분과 제목·선택 가족을 함께 표시하는 크롭. 제목은 원본 좌표 y≈100에 있고 크롭 y=80–330 안에 포함됩니다.
- 사진 읽기: 2번 후반의 준비·읽기 설명과 기존 실제 버튼 요청 장면.
- 수정 이유: 3번의 가상 오류 사례 및 원본 두 정/가상 한 정 설명과 같은 시점의 원본·입력값 대조.
- 수정 확인: 3번 후반과 사용자 수정 표시·명시적 대조 확인.
- 변경값: 4번 앞부분만 사용. 말미의 중복 설명은 3번 말미와 파형 상관 0.9554로 확인해 제외.
- 5번의 함량/투약량 설명 → 상세 비교 설명 → 의학적 판정 아님 설명을 각각 해당 카드·상세표·주의 문구에 배치. 두 문단 경계 무음에 4초/3초 읽기 시간을 삽입.
- 복용 상태 선택 → 저장 완료: 6번과 각각 미선택·선택·저장·완료 화면.
- 기존 실조회: 8번의 도입/실제 식약처/사진 검증/미검증 경계를 각각 전체 기록 카드와 해당 초점 카드에 연결. 신규 Mock을 실조회 화면으로 바꾸지 않음.
- 보류: 9번과 비교 미실행·사유·원본 보존을 보여 주는 기존 화면.
- 재조회·모바일: 10번 순서와 사진 → 자료 → 모바일 전체 → 카드 → 복용 상태.
- 11번 종료 뒤 약 1.7초를 두고 PPT 복귀. 모든 여유를 끝에 몰지 않음.
