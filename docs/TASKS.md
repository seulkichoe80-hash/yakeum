# 담당영역

현재 문서는 4명의 담당영역만 정의한다. 세부 기능 개발 Task는 팀 협의 후 별도로 작성한다.

## TASK A / AI 문서인식

- 약봉투
- 처방전
- 건강기능식품
- AI 정보 추출
- 사용자 수정·확정

## TASK B / 데이터·백엔드

- 심평원 투약이력 파일
- 식약처 공식 데이터
- 제품/성분/함량/단위 정규화
- DUR 근거 연결

## TASK C / Frontend

- 가족 관리
- 자료 등록
- AI 결과 확인/수정
- 현재 복용목록
- 변경사항
- Timeline
- 공식 근거 UI

## TASK D / 핵심엔진·통합

- Reconciliation Engine
- Current Intake State
- Backend/API 통합
- E2E 테스트
- 배포
