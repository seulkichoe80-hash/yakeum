10/31의 현실적인 완료 기준은 **가상 자료를 사용하는 웹 MVP의 핵심 흐름과 재현 가능한 시연 실행본**이다.

실제 건강정보 사용을 위한 운영 인증·암호화·동의/삭제·백업/복구는 '있으면 좋은 기능'이 아니라

## 실제 Gemini 준비

- 공식 문서에서 gemini-3.5-flash-lite(Stable, 이미지/구조화 출력)를 확인했다.
- Standard 요금: 입력 $0.30/100만 tokens, 출력(생각 포함) $2.50/100만 tokens.
- 합성 800x500 1장·1회는 가정한 입력 2000~4000/출력 500~4096 기준 약 $0.002~$0.012 예상.
  무료 할당량 적용이면 $0일 수 있으며 실제 측정/강제 금액 상한은 아니다.
- 공식 공개 문서 접속과 API host HEAD 응답은 확인했으나 계정 인증·실제 모델 사용 권한은 미검증.
- 사용자가 키를 등록했다고 안내했지만 현재 작업 프로세스에는 키가 보이지 않는다. 키가 잘못됐다고 단정하지 않는다.
  현재 작업으로의 주입/준비 상태를 확인해야 하며 채팅으로 키를 다시 받지 않는다.
- 1회 실제 분석/모델 조회는 아직 미실행. LIVE_ENABLED 기본 0, 호출 한도 1, 재시도 0.
- 공통 데이터 확인과 사용자의 별도 복용 확인, 원본/수정 분리를 유지한다.
- 실제 추출 약품이 Mock 공식 목록에 없으면 비교 보류된다. 실제 식약처 연결 완료가 아니다.

공식 근거: https://ai.google.dev/gemini-api/docs/models/gemini-3.5-flash-lite 및 /docs/pricing.

## 실제 식약처 준비와 차단 항목

- 기존 RealMfdsClient는 있지만 HIRA pipeline/사진 정규화 경로는 MockMfdsClient를 사용한다.
- api_config.yaml의 응답 field/성분 분리/endpoint는 '실응답 미검증 가정'이다. 그대로 실제 검증 완료로 표시하지 않는다.
- 보험 약품코드와 품목기준코드 ITEM_SEQ를 혼동하지 않기. 현 기본 보험코드 조회는 명세 미확인이라 비활성이다.
- 성분·제품 함량·함량 단위·복합제 필드, 건강기능식품 별도 ID 체계와 성분 제공 여부를 공식 명세로 확인해야 한다.
- 필요한 것: 공공데이터포털의 해당 서비스 활용 승인, MFDS_API_KEY 비밀 주입,
  개발/운영키 조건·할당량/비용·응답 코드·샘플 명세, www.data.go.kr(문서)/apis.data.go.kr(API) 네트워크 허용.
- 이번 공개 문서 검색 접속은 403 차단. 실제 apis.data.go.kr 조회는 하지 않았다.
- 최초 실제 조회의 목적·개수·비용 조건을 안내하고 승인받기 전 실행하지 않는다.
- 앱 연결은 출처 표시/API 버전과 소비자 검사도 함께 설계해야 한다. 기존 LOCAL_MOCK를 실제 응답처럼 바꾸지 않는다.

## 웹 배포 결정사항과 제한

Dockerfile + 정적 빌드/동일 주소 API는 이번에 로컬 검증했다. 실제 호스팅 게시/운영 배포는 하지 않았다.
필요 조건은 Python 컨테이너/단일 인스턴스, /data 영속 볼륨, HTTPS 진입점,
정확한 허용 Origin, 비밀 환경변수, 접근 제한된 가상 시연 환경, 예산 확인이다.
정적 프론트만 배포하거나 임시 디스크 플랫폼에 SQLite를 두면 현재 저장 기능이 유지되지 않는다.
플랫폼의 무료 요금제·영속 볼륨 지원은 확인 전 무료라고 단정하지 않는다.
운영용 서비스로 전환하려면 production 인증/권한, 데이터 보호/삭제/복구 정책과 실제 검증이 더 필요하다.

남은 결정: 배포 대상/공개 범위/비용, 실제 API 시험 승인, 보류 사진의 '검토용 저장' 확장 여부.
현 사진 보류 저장 제한은 유지한다. 정책 결정을 기다리는 동안 독립 검사와 시연 준비를 진행한다.
